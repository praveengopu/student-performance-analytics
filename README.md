# Student Performance Analytics

A learning-focused data analytics project using Python, Pandas, NumPy, and Matplotlib.

## Dataset limitation
This project uses a synthetic student dataset created for educational and portfolio demonstration purposes. It does not represent real VIT student records or real institutional outcomes.

## Questions explored
- How do attendance and study hours relate to final marks?
- What is the average mark by study-hours group?
- Which students may need additional academic support based on attendance and marks?
- How are marks distributed across the dataset?

## Workflow
1. Load and inspect the dataset
2. Check missing values and duplicates
3. Create derived performance categories
4. Calculate summary statistics
5. Explore relationships between attendance, study hours, and marks
6. Save summary tables and charts

## How to run

```bash
python -m pip install -r requirements.txt
python src/analyze_performance.py
```
